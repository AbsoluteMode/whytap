# API hints

## Behavior

Settings -> API & Models shows API hints as its fourth internal tab, after
API keys, Models and Costs. Since 2026-11-19 the offers are rows grouped under
**Speech to text**, **Language models** and **Web search**, replacing the
earlier grid of large cards: cards needed scrolling at five offers and could
not be compared within one job. A row shows the monochrome brand mark (a globe
when Whytap has none), the provider, what it takes to start, the allowance with
its period, and **Get offer**.

What it takes to start has three values, and rows keep this order within a
group: **No card needed**, **Card required**, **Paid plan** (highlighted, so a
subscription benefit such as Claude Max does not read as free). Allowances stay
strings with their own units ($, credits, requests, Neurons): they are not
converted to one scale or sorted by size.

**Get offer** opens the official page. Hovering it or focusing it with the
keyboard opens a popover beside the button (trailing edge, so it covers neither
the button nor the row) with the conditions and that offer's own check date.
Unlike Costs, the row itself is not the trigger, because the row has a control
to click. VoiceOver reads the same conditions and date as the button's hint.

The header says **Reviewed monthly · Last checked <date>**, where the date is
the newest check among the offers. Each offer keeps its own date: adding or
rechecking one offer does not reverify the rest. Reviewing monthly is a
maintenance promise: whoever refreshes the offers updates the dates here.

The tab has no footer: on 2026-11-19 the user removed its two explanatory
lines and the **Add API key** button; keys are added from the API keys tab.
Tavily is not a model provider: its row points to its tile in
**API & Models → API keys**, alongside all other keys. No account or
routing enum is added. The standalone sheet, no longer presented by the app,
retains its footer controls (Add API key, Done).
The shared surface and period behavior are recorded in
[feature costs](2026-10-20-feature-costs.md).

Only offers whose key works in Whytap as it is are listed: a hint the user
cannot act on has no value (user decision, 2026-11-19). Groq and Cloudflare
Workers AI were drafted as rows pointing to the OpenAI-compatible server path
(text features only, not Agent, never tried with a real key) and removed the
same day until Whytap supports them properly. Also left out until an adapter
exists: Exa search; Speechmatics, AssemblyAI and Gladia speech; Groq and
Cloudflare recorded-audio Whisper. Their terms as of 2026-11-19 are kept under
Offer evidence for that later work.

The card is editorial guidance, not a live balance or eligibility check. Opening
it makes no requests and changes no keys or routes. Provider links open only
when clicked. Keyboard and accessibility behavior use native SwiftUI controls.

Whytap itself is free; provider usage can be covered within a free allowance or
by an existing paid subscription. Do not promise permanently unlimited free
operation. Local model execution is not a suggested route: it was removed.

## Offer evidence

Added, rechecked or researched for later on **2026-11-19** (web search of the official pages and a research agent's comparison; no accounts were registered). Groq and Cloudflare are not shown in the tab yet:

- [Groq rate limits](https://console.groq.com/docs/rate-limits): the Free plan
  lists about 1,000 requests a day, 30 a minute and 8,000 tokens a minute for
  its larger text models; exact numbers are per model and shown in the account.
  No card is asked for on Free according to Groq's community answers; the
  pricing pages do not state it outright.
- [Cloudflare Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/):
  10,000 Neurons a day at no charge, shared by all models;
  [OpenAI-compatible endpoints](https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility)
  take an API token and the account ID in the base URL.
- ElevenLabs: the Free plan needs no card and is for non-commercial use.
- [OpenAI API credits for ChatGPT subscribers](https://developers.openai.com/api/docs/guides/chatgpt-api-credits):
  ChatGPT Pro tiers receive $100, $200 or $500 of API credit a month, Business
  up to $500 per workspace; Plus and Enterprise receive none. Claim after seven
  days in ChatGPT billing by linking an API organization owned by the same
  account. Credits expire at the end of the billing cycle. Maxim confirmed on
  2026-11-19 that he claims $200 a month this way.

The four pre-existing offers were checked on **2026-10-19** against these official sources:

- [Deepgram pricing](https://deepgram.com/pricing): new-account $200 starter
  credit, then usage-based billing; no card needed to start. Treat this as a
  one-time starting allowance, not a monthly credit.
- [ElevenLabs developer API](https://join.elevenlabs.io/api/developer-api):
  Free includes 10,000 credits per month and API access.
  [API pricing](https://elevenlabs.io/pricing/api) lists distinct Scribe realtime
  and batch allowances. Do not convert credits to a universal audio duration.
- [OpenRouter's cost guide](https://openrouter.ai/blog/tutorials/how-to-get-the-lowest-cost-llm-inference-on-openrouter/):
  free models allow 50 requests/day and 20/minute without purchasing credits.
  Agent tool cycles may require several requests. Use an explicit `:free` model
  suited to the feature; do not automatically choose or replace a route.
- [Claude monthly API credits](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans):
  Max 5x supplies $100/month, Max 20x $200/month. Claim after seven days on an
  eligible subscription by linking a Console organization in Claude billing.
  Use its Anthropic key for the Agent feature. Credits expire each billing
  cycle, are shared within that organization, and do not pay for requests sent
  through Whytap's OpenRouter account. Free and Pro plans are ineligible.

Tavily was checked on **2026-10-22**:

- [Tavily pricing](https://www.tavily.com/pricing): Researcher Free includes
  1,000 API credits each month; no credit card is required.
- [Tavily credits](https://docs.tavily.com/documentation/api-credits): basic
  search costs one credit per call; advanced search costs two. The card says
  1,000 search credits, not 1,000 agent questions or every kind of API request.
  Whytap's native search uses basic search; one agent turn can make several calls.

The verification date is visible on each card. When changing an offer,
recheck its official source and update the date and this record together.

## Delivery dependency

Tavily key setup uses the native agent credential store and its tile in
API & Models → API keys. The original runtime and hint shipped together; the user
confirmed that search keys belong beside all other API keys on October 22. The hint adds no code
dependency on the native runtime and never reads keys or calls Tavily.

The original feature extends the API & Models sheet coordinator from PR #43. The only
shared runtime file is APIAndModelsView; provider account, routing and key code
are unchanged. The builder must preserve PR #48's independent model/provider UI
changes when reconciling that shared file.
