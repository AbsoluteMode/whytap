## Free API keys

Whytap is free: you bring the keys. These providers give an allowance without a card,
so you can try Whytap without spending anything. The same list is in
Settings → API & Models → API hints.

<sub>Reviewed monthly · Last checked November 21, 2026</sub>

| For | Provider | Free allowance | Good to know | Checked |
|---|---|---|---|---|
| Speech to text | [Deepgram](https://deepgram.com/pricing) | **$200** one-time starter credit | Speech recognition credit for new accounts. It does not expire. No card needed to start. | November 21, 2026 |
| Speech to text | [ElevenLabs](https://elevenlabs.io/pricing) | **10,000** free credits each month | The Free plan includes Speech to Text, for non-commercial use with attribution. Speech to Text spends credits per minute of audio. | November 21, 2026 |
| Language models | [OpenRouter](https://openrouter.ai/models?max_price=0) | **50 / day** free model requests | Choose a :free model. Limit: 20 requests a minute; buying $10 of credit once raises the daily limit to 1,000. Tool support and availability vary; agent turns may use several requests. | November 21, 2026 |
| Web search | [Tavily](https://www.tavily.com/pricing) | **1,000** free search credits each month | Web search for Agent. No card required. One basic search uses one credit. Add the Tavily key in API keys. | November 21, 2026 |

Allowances and terms belong to the providers and can change; check the linked page before you rely on one.
